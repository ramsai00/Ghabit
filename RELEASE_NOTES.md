# Release Notes

## 0.1.2 - 2026-04-18
- Added Express + SQLite backend persistence.
- Added dashboard summary metrics for total habits, active tasks, todos due, and completed today.
- Added recent activity log in the todo sidebar.
- Improved large-screen layout, todo sidebar spacing, and summary dashboard cards.
- Added progress chart for habit completion history.

## 0.1.1 - 2026-04-17
- Added recurrence controls for habits and todos.
- Added weekly day selection and start/end date range configuration.
- Added one-time habit and todo scheduling with due date support.
- Added schedule-aware status labels for recurring tasks.

## 0.1.0 - 2026-04-17
- Added the first habit tracker UI with local persistence.
- Added habit and todo sections with status labels for upcoming, active, done, and missed.
- Added browser notification support and a test notification button.
- Added in-app fallback alerts when browser notifications do not appear.
- Added local server run instructions in `README.md`.

## 0.0.1 - initial scaffold
- Basic HTML/CSS/JavaScript scaffold for the tracker.
- Habit and todo sections with add/delete actions.
